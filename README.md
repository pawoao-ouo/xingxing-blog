# 醒醒的个人博客

基于 [Fuwari](https://github.com/saicaca/fuwari) 魔改的静态个人博客。

- 域名：`mua.l.cd`（准备指向 GitHub Pages）
- 仓库：`pawoao-ouo/xingxing-blog`
- 内容：`src/content/` 下的 Markdown
- 站点配置：`src/config.ts`
- 主题色：站内可调（默认暖粉 hue 345）

## 本地开发

```bash
pnpm install
pnpm dev
```

## 构建

```bash
pnpm build
```

## 部署

推送到 `main` 后，GitHub Actions 自动构建并发布到 GitHub Pages。
